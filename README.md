# Personal Multimedia Portfolio Website

## 1. Project Overview

This project is a personal multimedia portfolio website developed using HTML, CSS and JavaScript as part of an individual coursework assignment.

The website showcases my personal background, technical skills, projects and understanding of multimedia concepts through animations and interactive elements.

The portfolio is designed with a clean, modern and responsive layout to provide visitors with an engaging browsing experience across different devices.

## 2. Objectives

The main objectives of this project are to:

- Develop a personal portfolio website using HTML, CSS and JavaScript.
- Showcase my background, interests and technical skills.
- Display at least three software development projects.
- Demonstrate different animation techniques using CSS and JavaScript.
- Apply responsive web design principles.
- Create an accessible online platform where visitors can learn about my work and experience.

## 3. Technologies Used

The following technologies were used in developing this project:

| Technology | Purpose |
|---|---|
| HTML5 | Creating the structure and content of the website. |
| CSS3 | Styling, layouts, responsive design and animations. |
| JavaScript | Adding interactivity and dynamic functionality. |
| Git | Tracking changes during development. |
| GitHub | Hosting the project repository. |
| GitHub Pages | Publishing the portfolio website online. |

## 4. Website Sections

The portfolio consists of the following main sections:

### Home
Introduces me and provides visitors with an overview of my portfolio.

### About Me
Provides information about my background, interests, education and technical skills.

### Projects
Showcases three software development projects:

1. **Public Service Complaint Analysis System** – A web-based system designed to help citizens submit and track public service complaints while supporting data analysis.

2. **CarePlus Healthcare Management System** – A healthcare management application designed to support patient-related activities and healthcare service management.

3. **Cloud-Based Student Collaboration Platform** – A project focused on providing students with a platform for collaboration and information sharing.

Each project includes a description and a link to its corresponding GitHub repository.

### Animated Concepts
Demonstrates different animation techniques implemented using CSS and JavaScript, including:

- Typing Animation
- Floating Animation
- Rotating Animation

These concepts demonstrate how animation can improve the visual appearance and user experience of a website.

## 5. Key Features

- Modern and visually appealing interface.
- Single-page navigation with different content sections.
- Interactive navigation.
- Responsive layout for different screen sizes.
- Project showcase with GitHub repository links.
- CSS-based animations and interactive effects.
- Hover effects and animated elements.
- Smooth and engaging user experience.

## 7. How to Run the Project Locally

To view the portfolio on your computer:

1. Clone the repository from GitHub:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the downloaded project folder in Visual Studio Code.

3. Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code.

4. Navigate through the different sections to explore the portfolio.
